# AI Translation & Localization Agent — Portfolio MVP

A working portfolio demonstration of an AI-powered translation and localization agent.

## What it demonstrates
- approved-translation reuse
- controlled terminology
- treatment decisioning
- European Spanish generation
- validation / QA notes
- human-review escalation
- governance boundaries

## Deployment
Deploy with Streamlit Community Cloud from a public GitHub repository.

Add this secret in the deployed app:

OPENAI_API_KEY = "your-key-here"

Never put the API key in the GitHub repository.

The app includes session-level request limits to reduce accidental API spend.
